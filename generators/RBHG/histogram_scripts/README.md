# RBHG Histogram Merging Scripts

This directory contains utilities for merging histogram files generated by the RBHG generator.

## Files

- **mergeHists.py** - Core histogram merging utility (single directory)
- **submit_mergeHists.py** - SLURM farm job submission wrapper (deprecated - use merge_all_histograms.py)
- **../../merge_all_histograms.py** - Batch processing tool for entire studies (recommended)

## Quick Start

### Option 1: Automatic (Recommended) - Batch Process Entire Study

Process all histogram directories in a study at once:

```bash
# Interactive (sequential, runs locally):
./merge_all_histograms.py output/RBHG/CPP_FFS1/ --interactive

# Farm submission (parallel, one job per directory):
./merge_all_histograms.py output/RBHG/CPP_FFS1/ --farm

# Using master config JSON:
./merge_all_histograms.py output/RBHG/CPP_FFS1/BC_FF1/run_period_master_config.json --farm
./merge_all_histograms.py output/RBHG/CPP_FFS1/ffs_master_config.json --interactive

# With cleanup (move txt files to archived_histograms/):
./merge_all_histograms.py output/RBHG/CPP_FFS1/ --farm --cleanup move
```

**Performance estimate:** ~1-5 minutes per directory interactively (depends on number of txt files)

### Option 2: Via prepareSimulation.py

When you run `prepareSimulation.py` with an RBHG configuration, you'll be prompted to merge histograms after successful completion.

### Option 3: Manual - Single Directory

Edit `mergeHists.py` and modify the `directories` list at the bottom of the file:

```python
directories = [
    "/path/to/your/output/directory"
]

for directory in directories:
    merge_histograms(directory, cleanup_mode='move')
```

Then run:
```bash
python generators/RBHG/histogram_scripts/mergeHists.py
```

## How It Works

The merging process:
1. Reads ALL `array_*.txt` files for each histogram type
2. Sums counts directly in memory (numpy) - no intermediate files
3. Creates **ONE ROOT file** with all merged histograms
4. No `hadd` needed - constructs the final ROOT file directly
5. Doesn't need NEVENTS_PERFILE - just processes whatever txt files exist

The script is self-contained and only needs the directory path - no config files required.

## Output

The merging process produces:
- `merged_histograms.root` - ROOT file with all merged histograms
- `array_*_merged.txt` - Text files with merged histogram data
- `archived_histograms/` - Original individual histogram files (if using `cleanup_mode='move'`)

## Histogram Directory Structure

The scripts expect histogram files in a `hists/` subdirectory:
```
your_output_directory/
├── hists/
│   ├── array_Egamma_0.txt
│   ├── array_Egamma_1.txt
│   ├── array_t_0.txt
│   ├── array_tvar_0.txt
│   └── ...
└── vectors/
```

After merging:
```
your_output_directory/
├── hists/
│   ├── merged_histograms.root
│   ├── array_Egamma_merged.txt
│   ├── array_t_merged.txt
│   ├── array_tvar_merged.txt
│   └── archived_histograms/
│       ├── array_Egamma_0.txt
│       ├── array_Egamma_1.txt
│       └── ...
└── vectors/
```

## Cleanup Modes

- `cleanup_mode=None` - Keep all original files
- `cleanup_mode='move'` - Move original files to `archived_histograms/`
- `cleanup_mode='delete'` - Delete original files (use with caution!)
